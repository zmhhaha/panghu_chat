# 虎博退出登录

右上角头像/用户名打开账号菜单，桌面和手机均提供「我的主页」「退出登录」。退出前确认共享会话影响；检测到未发布标题、正文或评论时额外提示。支持外部点击及 Escape 关闭菜单。

退出使用 `/oauth2/sign_out?rd=%2Fsigned-out`。匿名 `/signed-out` 页面只提供显式重新登录，不自动跳回受保护首页。HTML 禁止缓存，主应用从浏览器往返缓存恢复时重新加载认证入口。

当前代理沿用 `.panghuer.top` 的 `_oauth2_proxy` 共享 Cookie，退出可能影响其他服务的代理会话。不会注销 Casdoor 统一账号；重新登录可能自动使用现有统一账号。本功能不宣称是仅退出虎博，也不是全局账号注销。

## 部署

同步代码后，先部署 Hublog 页面和路由，再应用 Hublog OAuth 代理的匿名退出页规则：

```bash
cd ~/armbianbegin/panghu_chat/hublog
bash deploy.sh
cd ~/armbianbegin/oauth/k8s
bash deploy-hublog-proxy.sh
```

不需要数据库迁移变更。仅更新 Hublog 镜像而未更新代理规则会导致退出页再次要求登录。

## 服务器验收（待部署后执行）

- 桌面和手机头像菜单可打开，外部点击/Escape 可关闭。
- 未发布正文、标题、评论的退出提示正确；取消后内容保留。
- 退出停留于匿名页面，无登录重定向循环。
- 手动重新登录恢复访问，浏览器后退不直接恢复旧账户页面。
- 检查其他服务的共享 Cookie 会话影响与确认文案一致。
